# Project skills

These are narrow project procedures, not a copy of a global discipline
framework. They link to the existing owners instead of restating thresholds,
commands or product requirements.

- [fileholder-investigate](fileholder-investigate/SKILL.md) — Stage error,
  unexplained result or regression.
- [fileholder-change](fileholder-change/SKILL.md) — approved implementation or
  bounded correction.
- [fileholder-evaluate](fileholder-evaluate/SKILL.md) — version, extraction or
  semantic evidence comparison.
- [fileholder-read-results](fileholder-read-results/SKILL.md) — explain a saved
  result without rerunning it.
- [fileholder-handover](fileholder-handover/SKILL.md) — verify and hand off an
  agreed change.

Each skill has a `fileholder-` ID matching its directory. Read the shared
[authority](../../docs/governance/authority.md) and
[workflow](../../docs/governance/workflows.md) rules first. Client discovery
varies; the [quickstart](../../docs/operations/agent-harness-quickstart.md) states
the native and manual fallback paths. Do not duplicate skills in per-client
folders.
