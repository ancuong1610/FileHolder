# Decisions

Consequential harness choices are recorded here. These are not retroactive
product history and do not replace accepted contracts or architecture.

Each decision file has:

```text
- ID: 0001
- Status: proposed | accepted | superseded | rejected
- Approval: owner approval when accepted
```

Only an actual owner approval may mark a decision `accepted`; a proposed choice is
not policy. An accepted decision must be indexed here and linked from the
[governance README](../README.md).
