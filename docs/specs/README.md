# Design specifications

Approved design specifications for new subsystems. A spec records what will be
built and why; the matching implementation plan lives in [plans](../plans/README.md).

A spec is not evidence that a feature exists or works. Keep private PDFs, raw
extraction data, credentials, internal endpoints and saved result text out of
specs. Name files `YYYY-MM-DD-<short-kebab-case-topic>-design.md`.
